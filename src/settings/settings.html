Scholar Reader — Settings

API keys

Stored only in this browser profile. Never sent anywhere except to the provider it belongs to.

Providers

The first is the default. If it runs out of quota, the next one with the same destination takes over. A provider with a different destination — the local model included — is never used automatically.

Sites that keep the browser's own viewer

One host per line, e.g. example.org. PDFs from these hosts are not intercepted.

Documents approved for sending

Revoking an approval makes the next outline request for that paper ask again. Outlines already cached still open without asking, since opening them sends nothing.
